# F2B Marketplace 🚀

A modern and responsive full-stack marketplace web application built to provide a smooth buying and selling experience. This project focuses on clean UI, real-time functionality, secure authentication, and scalable architecture.

## 🌟 Project Overview

F2B Marketplace is designed as an online platform where users can explore products, manage listings, and interact through a user-friendly interface. The project was developed with the guidance of ChatGPT to improve full-stack development skills, practical implementation knowledge, and real-world project experience.

This project demonstrates:

* Full-stack web development concepts
* Frontend and backend integration
* Authentication and database handling
* Responsive modern UI/UX
* API integration and project deployment
* GitHub version control and project management

# 🚀 Installation & Setup

## 1️⃣ Clone the Repository

```bash
git clone <YOUR_GITHUB_REPOSITORY_LINK>
```

## 2️⃣ Navigate to Project Folder

```bash
cd f2b-Marketplace
```

## 3️⃣ Install Dependencies

### Frontend

```bash
cd frontend
npm install
```

### Backend

```bash
cd backend
npm install
```

---

# ▶️ Run the Project

## Start Backend Server

```bash
npm start
```

## Start Frontend

```bash
npm run dev
```

---

# 🔑 Environment Variables

Create a `.env` file in the backend folder and add:

```env
MONGO_URI=your_mongodb_connection
JWT_SECRET=your_secret_key
PORT=5000
```
